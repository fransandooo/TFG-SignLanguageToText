================================================================================
                     PREGUNTAS FRECUENTES
================================================================================

Q: ¿Cuánto espacio ocupa en GitHub?
A: ~7 GB. GitHub permite repositorios privados de hasta 100 GB gratis.

Q: ¿Puedo hacer el repositorio público después?
A: Sí, pero PRIMERO elimina utils/kaggle.json del historial con:
   git filter-branch o BFG Repo-Cleaner (busca tutoriales)

Q: ¿Qué pasa si olvido mi contraseña de GitHub?
A: Puedes recuperarla desde https://github.com/password_reset

Q: ¿Necesito subir archivos grandes (.pt)?
A: Sí, los modelos .pt (12 MB) están bien. GitHub soporta archivos hasta 100 MB.
   Para archivos más grandes usa Git LFS.

Q: ¿Qué es un token de acceso personal?
A: Es una contraseña especial para Git. GitHub te pedirá crear uno si usas HTTPS.
   Ve a: GitHub → Settings → Developer settings → Personal access tokens

Q: ¿Puedo trabajar desde otro ordenador?
A: Sí! Clona el repo con: git clone <url>

                         SOLUCIÓN DE PROBLEMAS
================================================================================

ERROR: "remote origin already exists"
SOLUCIÓN: git remote remove origin && git remote add origin <url>

ERROR: "permission denied"
SOLUCIÓN: Verifica tu usuario/contraseña o configura SSH

ERROR: "failed to push some refs"
SOLUCIÓN: git pull --rebase origin main && git push

ERROR: "large files detected"
SOLUCIÓN: Verifica que no haya archivos >100MB con: find . -size +100M
